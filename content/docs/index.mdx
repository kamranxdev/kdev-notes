### Welcome to Kamran's Knowledge Base

Imagine walking into a university library. The shelves hold thousands of massive, leather-bound books. Every detail is recorded, but the language is dry, academic, and dense. Finding what you need is slow, and understanding the core concept requires wading through pages of technical jargon.

Now imagine that same library, but next to each shelf stands a senior engineer who hands you a sticky note containing a vivid analogy: *"Think of the JVM stack like a chef's temporary write-and-erase clipboard, and the heap like the main shared prep table."* 

This knowledge base is that senior engineer. It is a **living, curated translator** designed to bypass surface-level definitions and focus directly on **first principles** and **mental models**.

#### 1. Web Development: The Dynamic Canvas
*   **Fundamentals**: The DOM rendering pipeline (a folding pop-up book), CSS specificity (a bidding auction), and JavaScript's Event Loop (a single-chef kitchen with helper windows).
*   **Frameworks**: Building custom workspaces in React and template structures in Angular.

#### 2. Mobile Development: Painting in Multi-City
*   **Android**: Writing native platforms using Kotlin and Java.
*   **Cross-Platform**: Flutter's approach of bringing its own paint, brushes, and canvas to draw identical, buttery-smooth 60/120fps murals across different operating systems.

#### 3. Databases: The Secure Safe Deposit Room
*   **SQL**: Building database house foundations (DDL) vs. moving furniture inside (DML), and navigating index trees.
*   **PL/SQL**: Managing context-switch roundtrips between the manager (PL/SQL engine) and the vault clerk (SQL engine) using bulk collections.

#### 4. Programming Languages: Esperanto Recipes
*   **Java**: Translating source code into a universal intermediate cooking language (bytecode) that any head chef JVM can run on any stove platform.

#### 5. Systems & Linux: The Lab Vault
*   **Unix & Linux**: Restricting access between the public lobby (User Space) and the sterile inner laboratory vault (Kernel Space) via system call slots.

### How to Navigate and Learn

To get the most out of these notes, follow this three-step pipeline:

1.  **Understand the Analogy First**: Do not skip the metaphors. They are not decoration; they are the hooks your brain needs to store and index the technical details.
2.  **Inspect the Code Playgrounds**: Every section contains complete, commented code examples demonstrating the rules in action.
3.  **Test Your Knowledge**: Take the multiple-choice quizzes at the end of each section to verify your retention. If you miss a question, review the section before moving forward.
