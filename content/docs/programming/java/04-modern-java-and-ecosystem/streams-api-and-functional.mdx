### 1. Streams API Mechanics

The Streams API processes collections declaratively as a pipeline assembly line.

```
  Source Data ──► filter() ──► map() ──► collect() (Terminal)
  [Conveyor Belt]  (Lazy)      (Lazy)    (Triggers execution)
```

*   **Intermediate Operations**: Lazy operations that transform a stream and return a new stream (e.g., `filter()`, `map()`, `sorted()`). They do not execute until a terminal operation is invoked.
*   **Terminal Operations**: Produce a side-effect or concrete result (e.g., `collect()`, `forEach()`, `reduce()`). Executing a terminal operation consumes the stream pipeline.

### 2. Stream Example: Grouping & Collectors

```java
import java.util.*;
import java.util.stream.Collectors;

public class StreamPipelineDemo {
    public record Transaction(String category, double amount) {}

    public static Map<String, Double> getTotalPerCategory(List<Transaction> txs) {
        return txs.stream()
            .filter(t -> t.amount() > 0.0) // Filter invalid amounts
            .collect(Collectors.groupingBy(
                Transaction::category,
                Collectors.summingDouble(Transaction::amount)
            ));
    }
}
```
