### 1. Inversion of Control (IoC) & Dependency Injection (DI)

*   **Inversion of Control (IoC)**: Transferring control of object creation, lifecycle management, and dependency wiring from application code to the Spring Framework container.
*   **Dependency Injection (DI)**: Passing dependent objects into a class (via constructor injection) rather than letting the class instantiate its dependencies using `new`.

```java
// Preferred: Constructor Injection
@Service
public class UserService {
    private final UserRepository userRepository;

    @Autowired
    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }
}
```

### 2. Spring Layered Architecture

```
  HTTP Request ──► @RestController ──► @Service ──► @Repository ──► Database
```

1.  **Controller Layer (`@RestController`)**: Handles HTTP requests, input validation, and maps DTO responses.
2.  **Service Layer (`@Service`)**: Encapsulates core business logic and transaction boundaries (`@Transactional`).
3.  **Repository Layer (`@Repository`)**: Interacts with the database using Spring Data JPA / Hibernate.
