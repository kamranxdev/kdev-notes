<Problem title="Problem 1: Custom Thread-Safe Blocking Queue">
<ProblemDescription>
Implement a thread-safe generic blocking queue `CustomBlockingQueue<T>` with:
1. Fixed capacity initialized via constructor.
2. Blocking `enqueue(T item)` method: if the queue is full, the calling thread blocks until space becomes available.
3. Blocking `dequeue()` method: if the queue is empty, the calling thread blocks until an item is added.
4. Use standard `synchronized`, `wait()`, and `notifyAll()` coordination without using `java.util.concurrent` classes.
</ProblemDescription>
<ProblemSolution>
```java
import java.util.LinkedList;
import java.util.Queue;

public class CustomBlockingQueue<T> {
    private final Queue<T> queue = new LinkedList<>();
    private final int capacity;

    public CustomBlockingQueue(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException("Capacity must be positive");
        this.capacity = capacity;
    }

    public synchronized void enqueue(T item) throws InterruptedException {
        while (queue.size() == capacity) {
            wait(); // Block until dequeue makes space
        }
        queue.add(item);
        notifyAll(); // Wake waiting threads
    }

    public synchronized T dequeue() throws InterruptedException {
        while (queue.isEmpty()) {
            wait(); // Block until enqueue adds item
        }
        T item = queue.poll();
        notifyAll(); // Wake waiting threads
        return item;
    }
}
```
</ProblemSolution>
</Problem>

<Problem title="Problem 2: Custom Hashing Map Implementation">
<ProblemDescription>
Write a custom simplified Map implementation `SimpleHashMap<K, V>`.
1. Support standard operations: `put(K key, V value)`, `get(K key)`, and `size()`.
2. Map hash values to a bucket array index.
3. Handle bucket collisions using a singly-linked list chain structure.
4. Rescale (rehash) table when load factor exceeds `0.75`.
</ProblemDescription>
<ProblemSolution>
```java
public class SimpleHashMap<K, V> {
    private static class Entry<K, V> {
        final K key;
        V value;
        Entry<K, V> next;

        Entry(K key, V value) {
            this.key = key;
            this.value = value;
        }
    }

    private Entry<K, V>[] table;
    private int size;
    private static final int INITIAL_CAPACITY = 16;
    private static final double LOAD_FACTOR = 0.75;

    @SuppressWarnings("unchecked")
    public SimpleHashMap() {
        table = new Entry[INITIAL_CAPACITY];
    }

    private int getIndex(K key, int cap) {
        return key == null ? 0 : Math.abs(key.hashCode()) % cap;
    }

    public V get(K key) {
        int index = getIndex(key, table.length);
        Entry<K, V> curr = table[index];
        while (curr != null) {
            if (curr.key == key || (curr.key != null && curr.key.equals(key))) return curr.value;
            curr = curr.next;
        }
        return null;
    }

    public void put(K key, V value) {
        int index = getIndex(key, table.length);
        Entry<K, V> curr = table[index];
        while (curr != null) {
            if (curr.key == key || (curr.key != null && curr.key.equals(key))) {
                curr.value = value;
                return;
            }
            curr = curr.next;
        }
        Entry<K, V> newEntry = new Entry<>(key, value);
        newEntry.next = table[index];
        table[index] = newEntry;
        size++;
        if ((double) size / table.length >= LOAD_FACTOR) resize();
    }

    @SuppressWarnings("unchecked")
    private void resize() {
        int newCap = table.length * 2;
        Entry<K, V>[] newTable = new Entry[newCap];
        for (Entry<K, V> head : table) {
            Entry<K, V> curr = head;
            while (curr != null) {
                Entry<K, V> next = curr.next;
                int idx = getIndex(curr.key, newCap);
                curr.next = newTable[idx];
                newTable[idx] = curr;
                curr = next;
            }
        }
        table = newTable;
    }
}
```
</ProblemSolution>
