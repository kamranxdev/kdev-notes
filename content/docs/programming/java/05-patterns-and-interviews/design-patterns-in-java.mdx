### 1. Singleton Pattern (Thread-Safe Double-Checked Locking)

Ensures a class has only one instance while providing a global access point.

```java
public class ThreadSafeSingleton {
    // volatile guarantees main memory visibility across threads
    private static volatile ThreadSafeSingleton instance;

    private ThreadSafeSingleton() {
        // Private constructor prevents direct instantiation
    }

    public static ThreadSafeSingleton getInstance() {
        if (instance == null) { // First check (no lock overhead)
            synchronized (ThreadSafeSingleton.class) {
                if (instance == null) { // Second check (with lock)
                    instance = new ThreadSafeSingleton();
                }
            }
        }
        return instance;
    }
}
```

### 2. Builder Pattern

Separates object construction from representation, ideal for complex objects with optional parameters.

```java
public class DatabaseConfig {
    private final String url;
    private final int port;
    private final int maxConnections;

    private DatabaseConfig(Builder builder) {
        this.url = builder.url;
        this.port = builder.port;
        this.maxConnections = builder.maxConnections;
    }

    public static class Builder {
        private String url;
        private int port = 5432; // Default
        private int maxConnections = 10; // Default

        public Builder url(String url) { this.url = url; return this; }
        public Builder port(int port) { this.port = port; return this; }
        public Builder maxConnections(int max) { this.maxConnections = max; return this; }

        public DatabaseConfig build() {
            if (url == null) throw new IllegalStateException("URL is required");
            return new DatabaseConfig(this);
        }
    }
}
```

### 3. Strategy Pattern

Defines a family of algorithms, encapsulating each one, and making them interchangeable at runtime.

```java
@FunctionalInterface
public interface PaymentStrategy {
    void pay(double amount);
}

public class CheckoutService {
    public void processPayment(double amount, PaymentStrategy strategy) {
        strategy.pay(amount);
    }
}
```
