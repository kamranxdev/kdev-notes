### 1. Generics & Compile-Time Type Safety

Generics enable types (classes and methods) to be parameterized by target data types, providing compile-time type safety and eliminating explicit casting.

---

### 2. Type Erasure Mechanics

To maintain backward compatibility with legacy Java 1.4 bytecode, Java implements generics via **Type Erasure**.

1.  **Compile Time**: The compiler uses generic type parameters to enforce strict type checking.
2.  **Bytecode Generation**: The compiler removes type parameter details and replaces them with their upper bound (or `Object` if unbound).
3.  **Casts**: Inserts synthetic type casts where necessary.

```java
// Written Source Code:
List<String> list = new ArrayList<>();
list.add("Java");
String item = list.get(0);

// Compiled Bytecode (Post Type Erasure):
List list = new ArrayList();
list.add("Java");
String item = (String) list.get(0);
```

---

### 3. Wildcards & The PECS Rule

Wildcards (`?`) represent unknown types. To safely handle generic collections, follow the **PECS** rule: **Producer Extends, Consumer Super**.

*   **Producer Extends (`? extends T`)**: Use when your collection **produces** (reads) data of type `T`. You can read elements as type `T` safely. **You cannot write** elements (except `null`) to a producer.
*   **Consumer Super (`? super T`)**: Use when your collection **consumes** (writes) data of type `T`. You can write elements of type `T` safely. Reads only yield generic `Object` references.

```java
public class PecsDemo {

    // Producer Extends: Reads numbers from list
    public static double sumOfList(List<? extends Number> list) {
        double sum = 0.0;
        for (Number n : list) {
            sum += n.doubleValue(); // Safe read
        }
        // list.add(10); // COMPILE ERROR: Cannot write to a producer
        return sum;
    }

    // Consumer Super: Writes integers to list
    public static void addIntegers(List<? super Integer> list) {
        list.add(1);
        list.add(2); // Safe write
        // Object item = list.get(0); // Reading only yields Object
    }
}
```
