### 1. Object-Oriented Pillars in Java

*   **Encapsulation**: Hiding internal object state behind private fields and providing controlled access via public methods.
*   **Inheritance**: Extending parent classes (`extends`) to reuse fields and behavior. Single class inheritance only.
*   **Polymorphism**: Treating objects of different subclasses through a common parent reference.
    *   *Compile-Time (Method Overloading)*: Multiple methods with identical names but different parameter lists.
    *   *Runtime (Method Overriding)*: Subclass provides a specific implementation of a parent method. The JVM determines which method to execute at runtime via **Dynamic Method Dispatch**.

### 2. Constructor Chaining: `super()` & `this()`

Constructor chaining ensures parent class state is fully initialized before subclass constructor logic executes.

```java
class Vehicle {
    private final String brand;
    
    Vehicle(String brand) {
        this.brand = brand;
    }
}

class Car extends Vehicle {
    private final int doors;
    
    Car(String brand, int doors) {
        super(brand); // MUST be the first statement in constructor
        this.doors = doors;
    }
}
```

### 3. Abstract Classes vs. Interfaces (Modern Java 9+)

| Feature | Abstract Class | Interface (Java 9+) |
| :--- | :--- | :--- |
| **Inheritance Model** | Single class extension (`extends`) | Multiple interface implementation (`implements`) |
| **Instance State** | Can declare private/protected instance fields | Cannot store instance state (variables are implicitly `public static final` constants) |
| **Methods** | Can have private, protected, abstract, or concrete methods | Abstract, `default`, `static`, or `private` helper methods |

### 4. Sealed Classes & Interfaces (Java 17+)

**Sealed classes** restrict which subclasses are permitted to extend them, establishing a closed, domain-safe hierarchy.

```java
// Permits only CreditCardPayment and PaypalPayment to extend Payment
public sealed class Payment permits CreditCardPayment, PaypalPayment {}

public final class CreditCardPayment extends Payment {}
public non-sealed class PaypalPayment extends Payment {}
```

### 5. Records: Immutable Data Carriers (Java 16+)

**Records** are transparent, final data carrier classes. The compiler automatically synthesizes `private final` fields, a canonical constructor, getters, `equals()`, `hashCode()`, and `toString()`.

```java
public record UserProfile(String username, String email, int age) {
    // Compact constructor for domain validation
    public UserProfile {
        if (age < 0) {
            throw new IllegalArgumentException("Age cannot be negative");
        }
    }
}
```
