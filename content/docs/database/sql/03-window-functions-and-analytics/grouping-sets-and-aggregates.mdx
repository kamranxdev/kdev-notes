## 🎲 Multidimensional Aggregation Extensions

When generating executive dashboard summaries, reporting tools often require aggregations at multiple hierarchical levels (e.g., total sales by region, total sales by product line, total sales by region + product line, and global grand total).

Instead of writing multiple `SELECT` queries linked with expensive `UNION ALL` statements, SQL provides dedicated multidimensional aggregation extensions:

### 1. GROUPING SETS
Allows defining multiple explicit grouping combinations in a single query pass:

```sql
SELECT region, product_category, SUM(revenue) AS total_revenue
FROM sales
GROUP BY GROUPING SETS (
    (region, product_category),  -- Group by Region + Category
    (region),                    -- Group by Region subtotal
    (product_category),          -- Group by Category subtotal
    ()                           -- Global Grand Total
);
```

### 2. ROLLUP
Produces hierarchical subtotals and grand totals from left to right:
* `GROUP BY ROLLUP (year, quarter, month)` expands into:
  1. `(year, quarter, month)`
  2. `(year, quarter)`
  3. `(year)`
  4. `()` (Grand Total)

### 3. CUBE
Generates all $2^N$ possible cross-tabulation combinations of the specified columns:
* `GROUP BY CUBE (region, category)` produces 4 sets: `(region, category)`, `(region)`, `(category)`, and `()`.

## 💡 Conditional Aggregation Pattern

Conditional aggregation embeds `CASE WHEN` logic directly inside standard aggregate functions (`SUM`, `COUNT`, `AVG`). This allows pivoting row-based data into formatted columnar reports in a single table scan.

```sql
-- Pivot quarterly sales into individual columns per employee
SELECT emp_id,
       SUM(CASE WHEN quarter = 'Q1' THEN revenue ELSE 0 END) AS q1_revenue,
       SUM(CASE WHEN quarter = 'Q2' THEN revenue ELSE 0 END) AS q2_revenue,
       SUM(CASE WHEN quarter = 'Q3' THEN revenue ELSE 0 END) AS q3_revenue,
       SUM(CASE WHEN quarter = 'Q4' THEN revenue ELSE 0 END) AS q4_revenue,
       SUM(revenue) AS total_annual_revenue
FROM quarterly_sales
GROUP BY emp_id;
```

## 💻 Practice Problems

<Problem title="Problem: Regional Sales Subtotals via ROLLUP">
<ProblemDescription>
Write a query against `store_sales` computing total revenue grouped by `country` and `city`, producing automated country subtotals and a global grand total.
</ProblemDescription>
<ProblemSolution>
Use `ROLLUP` to generate hierarchical subtotals:

```sql
SELECT country, city, SUM(revenue) AS total_revenue,
       GROUPING(country) AS is_country_subtotal,
       GROUPING(city) AS is_grand_total
FROM store_sales
GROUP BY ROLLUP (country, city);
```
</ProblemSolution>
</Problem>
