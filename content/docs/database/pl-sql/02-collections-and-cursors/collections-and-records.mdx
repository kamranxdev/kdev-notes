## 🗂️ PL/SQL Collection Architecture

Collections are single-dimensional array structures used to store homogenous data elements in memory inside a PL/SQL block session.

Oracle PL/SQL supports three distinct collection structures:

```
                               PL/SQL Collections
                                       │
        ┌──────────────────────────────┼──────────────────────────────┐
        ▼                              ▼                              ▼
Associative Arrays              Nested Tables                      Varrays
 (Index-by Tables)           (Unbounded Sets)              (Fixed Capacity Limit)
 Keys: Integer/String        Starts NULL (Constructor)     Starts NULL (Constructor)
 PGA Memory Only             PGA or Stored DB Table        PGA or Stored DB Table
```

### 1. Associative Arrays (Index-by Tables)
* **Mechanics**: In-memory key-value dictionary. Keys can be integers or strings (`VARCHAR2`).
* **Analogy**: *A private desk address book.*
* **Behavior**: Does not require constructor initialization. Cannot be stored directly inside database table columns.

```sql
DECLARE
  -- Define dictionary mapping employee IDs to department names
  TYPE type_dept_map IS TABLE OF VARCHAR2(100) INDEX BY PLS_INTEGER;
  v_depts type_dept_map;
BEGIN
  v_depts(101) := 'Engineering';
  v_depts(102) := 'Finance';
  DBMS_OUTPUT.PUT_LINE('Dept: ' || v_depts(101));
END;
/
```

### 2. Nested Tables
* **Mechanics**: Dynamic, unbounded sets. Subscripts are dense positive integers starting at 1.
* **Analogy**: *A dynamic chest of filing drawers.*
* **Behavior**: Starts uninitialized (`NULL`). **Must be initialized using a constructor** (e.g., `type_name()`) before assigning elements or invoking `.EXTEND`.

```sql
DECLARE
  TYPE type_name_list IS TABLE OF VARCHAR2(100);
  v_names type_name_list := type_name_list(); -- Constructor initialization
BEGIN
  v_names.EXTEND; -- Allocate slot 1
  v_names(1) := 'Alice';
END;
/
```

### 3. Varrays (Variable-Size Arrays)
* **Mechanics**: Bounded array with a fixed declared maximum capacity limit.
* **Analogy**: *A rigid cardboard egg carton with a fixed number of slots.*
* **Behavior**: Must be initialized with a constructor; throws subscript errors if `.EXTEND` exceeds declared capacity limit.

---

## 🛠️ Collection Built-In Methods

* `.COUNT`: Returns the total number of elements in the collection.
* `.EXTEND(n)`: Allocates $n$ additional slots at the end of a Nested Table or Varray.
* `.DELETE(n)`: Removes element at index $n$.
* `.EXISTS(n)`: Returns `TRUE` if element exists at subscript $n$.
* `.FIRST` / `.LAST`: Returns the lowest and highest index subscripts in the collection.

## 💻 Practice Problems

<Problem title="Problem: Populating and Iterating Varrays">
<ProblemDescription>
Declare a Varray capable of holding up to 3 emergency phone numbers. Initialize it using a constructor, add 3 numbers dynamically using `.EXTEND`, and loop through the array to print each phone entry.
</ProblemDescription>
<ProblemSolution>
```sql
DECLARE
  TYPE type_phones IS VARRAY(3) OF VARCHAR2(20);
  v_phone_list type_phones := type_phones(); -- Constructor
BEGIN
  -- Add phone numbers dynamically
  v_phone_list.EXTEND(3);
  v_phone_list(1) := '+1-555-0192';
  v_phone_list(2) := '+1-555-0193';
  v_phone_list(3) := '+1-555-0194';

  -- Loop through collection
  FOR i IN 1..v_phone_list.COUNT LOOP
    DBMS_OUTPUT.PUT_LINE('Phone #' || i || ': ' || v_phone_list(i));
  END LOOP;
END;
/
```
</ProblemSolution>
</Problem>
