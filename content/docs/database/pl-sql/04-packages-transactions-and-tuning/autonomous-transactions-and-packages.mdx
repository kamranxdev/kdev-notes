## 📓 Autonomous Transactions: Independent Logbooks

By default, all DML statements executed inside a PL/SQL block participate in the main session transaction. If the main transaction rolls back, all DML operations roll back together.

An **Autonomous Transaction** is an independent transaction block spawned by a parent transaction. It can execute DML statements and issue an independent `COMMIT` or `ROLLBACK` without affecting the state of the main transaction.

* **Analogy**: *A separate logbook notebook.* You open a separate logbook, write down error messages, commit them, and close the book. Even if you rip up and burn the main transaction contract later, the entries recorded in the separate logbook remain intact.

```sql
CREATE OR REPLACE PROCEDURE log_error_autonomous (
    p_err_msg VARCHAR2
) IS
  PRAGMA AUTONOMOUS_TRANSACTION; -- Instructs Oracle to run independently
BEGIN
  INSERT INTO error_logs (log_msg, log_timestamp)
  VALUES (p_err_msg, SYSDATE);
  
  COMMIT; -- Commits ONLY the error log entry!
END;
/
```

## 📦 PL/SQL Package Architecture

A **Package** is an encapsulated database schema object that groups logically related procedures, functions, variables, cursor definitions, and types together under a single namespace.

A PL/SQL package consists of two distinct components:

```
                            Package Architecture
                                     │
        ┌────────────────────────────┴────────────────────────────┐
        ▼                                                         ▼
 Package Specification (`CREATE PACKAGE`)           Package Body (`CREATE PACKAGE BODY`)
 Public Interface / API Contract                    Private Implementation Logic
 Declares exposed subprograms & types               Implements public & private methods
 Compiles independently                             Modifiable without invalidating callers
```

### 1. Package Specification (Public Interface)
Declares all public procedures, functions, types, and constants accessible by calling applications:

```sql
CREATE OR REPLACE PACKAGE hr_pkg IS
  -- Public constant declaration
  c_max_raise CONSTANT NUMBER := 0.20;
  
  -- Public procedure interface specification
  PROCEDURE promote_employee(p_emp_id IN NUMBER, p_raise_pct IN NUMBER);
END hr_pkg;
/
```

### 2. Package Body (Private Implementation)
Contains the actual code implementation for all procedures declared in the specification, as well as private helper procedures and package state variables hidden from external view:

```sql
CREATE OR REPLACE PACKAGE BODY hr_pkg IS
  -- Private helper function hidden from public access
  FUNCTION validate_raise(p_pct IN NUMBER) RETURN BOOLEAN IS
  BEGIN
    RETURN p_pct <= c_max_raise;
  END validate_raise;

  PROCEDURE promote_employee(p_emp_id IN NUMBER, p_raise_pct IN NUMBER) IS
  BEGIN
    IF validate_raise(p_raise_pct) THEN
      UPDATE employees SET salary = salary * (1 + p_raise_pct) WHERE employee_id = p_emp_id;
    END IF;
  END promote_employee;
END hr_pkg;
/
```

## 🚀 Key Advantages of PL/SQL Packages

1. **Encapsulation & Security**: Hides complex business logic inside the package body while exposing clean public interfaces.
2. **Performance (Memory Pinning)**: When a package subprogram is invoked for the first time, the **entire package is loaded into the Shared Pool RAM**. Subsequent calls execute instantly without disk I/O compilation overhead.
3. **Session State Persistence**: Variables declared in the package specification retain their memory values throughout an application user session.

## 💻 Practice Problems

<Problem title="Problem: Package Logging Implementation">
<ProblemDescription>
Create a PL/SQL Package named `logger_pkg` with a public procedure `log_msg(p_text IN VARCHAR2)` configured as an autonomous transaction so error logging survives main transaction rollbacks.
</ProblemDescription>
<ProblemSolution>
Package Specification:

```sql
CREATE OR REPLACE PACKAGE logger_pkg IS
  PROCEDURE log_msg(p_text IN VARCHAR2);
END logger_pkg;
/
```

Package Body:

```sql
CREATE OR REPLACE PACKAGE BODY logger_pkg IS
  PROCEDURE log_msg(p_text IN VARCHAR2) IS
    PRAGMA AUTONOMOUS_TRANSACTION;
  BEGIN
    INSERT INTO system_logs (log_body, log_date) VALUES (p_text, SYSDATE);
    COMMIT;
  END log_msg;
END logger_pkg;
/
```
</ProblemSolution>
</Problem>
